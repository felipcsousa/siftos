## Scenario

A technical bug with no material product impact — but the repo has rich
product context. SiftOS must not add ceremony just because context exists.

## What SiftOS should do

- Fix the flaky test. Zero product framework: no PDR, no critique score,
  no alignment discussion, no workflow names.
- A single product-aware sentence is acceptable only if genuinely
  material; here it is not.

## What baseline likely does

Fixes the test. The assertion is that SiftOS does the same without adding
bureaucracy.

## Gold check

0 product-ceremony tokens (PDR, critique, align, strategy, DEC-XXXX).

## Rubric focus

ceremony, actionability.
