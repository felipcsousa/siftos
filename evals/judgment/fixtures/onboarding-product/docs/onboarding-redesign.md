# Onboarding redesign — proposal

## Problem

Activation is 21%. Users drop before first value.

## Solution

Rebuild the onboarding flow:

- New step-by-step wizard (7 screens).
- AI-powered "quick start" assistant that configures the workspace.
- Predictive task templates based on team role.
- Real-time progress analytics dashboard.
- In-product survey at step 3 and step 6.

## Success

Improves activation.

## Timeline

6 weeks, 2 engineers.
